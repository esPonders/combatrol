# Contributing

Please describe bugs or balance proposals in an issue. Include game and mod versions, reproduction steps, and relevant log excerpts after removing personal information.

Do not include game or Unity assemblies, personal recordings, profile configurations, credentials, or local build archives. Keep gameplay rules testable without Valheim and avoid assembly scans per frame. State which changes were tested in game and which were checked only offline. Multiplayer changes need testing across clients.

No redistribution license has been selected yet. Contact the repository owner before distributing derivative versions.
